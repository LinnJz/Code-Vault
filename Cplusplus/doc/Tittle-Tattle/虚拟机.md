## 虚拟化场景下Linux网络模式有哪些

在虚拟化场景下主要指导虚拟机构建的**桥接模式（Bridged Mode）**、**NAT（网络地址转换）模式**和**仅主机（Host-Only）模式**。

---

## 三种主流模式详解

### 1️⃣ 桥接模式

**原理**：虚拟机虚拟网卡直接"桥接"到物理主机的物理网卡上，虚拟机在局域网中获得一个独立的身份。

| 项目                 | 说明                                                 |
| -------------------- | ---------------------------------------------------- |
| IP地址               | 与宿主机在同一网段，拥有独立IP                       |
| 访问关系             | 可访问局域网内所有设备，也可被局域网其他设备直接访问 |
| 外网访问             | ✅ 可以                                               |
| 与宿主机通信         | ✅ 通过局域网                                         |
| 与局域网其他设备通信 | ✅ 可被直接访问                                       |

**优点**：IP独立、配置灵活、可被局域网其他设备直接访问、适合搭建对外服务
**缺点**：占用真实网段IP、局域网设备过多时容易IP冲突、可能暴露于局域网攻击风险

**适用场景**：需要对外提供服务的服务器、模拟真实网络环境、局域网内多设备互联协同测试

### 2️⃣ NAT 模式

**原理**：宿主机充当虚拟"路由器"，通过地址转换技术为虚拟机提供网络访问，虚拟机共享宿主机IP上网。

| 项目                 | 说明                                         |
| -------------------- | -------------------------------------------- |
| IP地址               | 私有IP（如192.168.x.x）                      |
| 访问关系             | 可单向访问外部网络，但外部无法直接访问虚拟机 |
| 外网访问             | ✅ 通过宿主机转发                             |
| 与宿主机通信         | ✅ 通过虚拟网络（VMnet8）                     |
| 与局域网其他设备通信 | ❌ 默认不能                                   |

**优点**：不占用真实网段IP、IP不会冲突、虚拟机网络相对隐蔽安全
**缺点**：无法被外部网络直接访问，需配置端口转发、依赖宿主机的网络可达性

**适用场景**：日常开发和测试、需要访问互联网但无需对外提供服务

### 3️⃣ 仅主机（Host-Only）模式

**原理**：创建一个完全与外界隔离的网络环境，虚拟机只能与宿主机通信，无法访问外网。

| 项目                 | 说明                         |
| -------------------- | ---------------------------- |
| IP地址               | 私有IP（通常通过VMnet1获取） |
| 访问关系             | 只能与宿主机互通             |
| 外网访问             | ❌ 不可以                     |
| 与宿主机通信         | ✅ 通过专用虚拟网络           |
| 与局域网其他设备通信 | ❌ 完全隔离                   |

**优点**：高度安全、配置简单、环境隔离性好
**缺点**：无法访问外网，更新或下载资源受限

**适用场景**：安全测试、恶意软件分析、需要绝对隔离的开发环境

## 核心区别速查表

| 维度             | 桥接模式     | NAT 模式                | 仅主机模式         |
| ---------------- | ------------ | ----------------------- | ------------------ |
| **IP分配**       | 局域网独立IP | 私有IP（如192.168.x.x） | 私有IP（VMnet1段） |
| **外网访问**     | ✅ 支持       | ✅ 支持                  | ❌ 不支持           |
| **被外部访问**   | ✅ 可直接访问 | ❌ 需配置端口转发        | ❌ 不可访问         |
| **IP冲突风险**   | ⚠️ 可能存在   | ✅ 无风险                | ✅ 无风险           |
| **默认虚拟网络** | VMnet0       | VMnet8                  | VMnet1             |
| **核心比喻**     | 独立户口     | 黑户黑户，寄居身份      | 彻底与世隔绝       |

---

## 除此之外的其它特殊模式

- **路由（Routed）模式**：虚拟交换机不使用 NAT 转发数据，虚拟机拥有独立于主机的子网，外部访问需要额外的路由表配置
- **隔离（Isolated）模式**：虚拟机只能相互通信，外部流量完全无法进出，形成一个完全封闭的网络空间
- **开放（Open）模式**：libvirt 不生成防火墙规则，可让用户完全手动管理虚拟机的网络安全策略
- **自定义网络**：可组合多种虚拟网络组件构建更复杂的高级网络方案

---

## 💡 选型指南

- **桥接模式**：需要局域网内其他设备直接访问虚拟机，或需要模拟真实网络环境时优先选择
- **NAT 模式**：日常开发测试首选，兼顾上网需求与安全性，配置简单
- **仅主机模式**：优先在安全测试、恶意软件分析等需要绝对隔离的场景中使用
