| Docker 概念                  | Kubernetes 概念                         | 说明                                                  |
| ---------------------------- | --------------------------------------- | ----------------------------------------------------- |
| 宿主机（物理机/VM）          | **Node**                                | 运行容器的机器                                        |
| Docker Daemon                | kubelet + 容器运行时（如 containerd）   | 负责管理本机容器                                      |
| 镜像（Image）                | 镜像（Image）                           | 完全一致，都是 OCI 标准                               |
| 容器（Container）            | **Pod 中的容器**                        | 单个隔离进程。K8s 最小单位是 Pod，Pod 可包含多个容器  |
| –（无直接对应）              | **Pod**                                 | 一组共享网络、存储、IPC 的容器，是 K8s 的原子调度单位 |
| Docker Network               | Kubernetes **Service / CNI**            | 容器网络模型不同，Service 提供稳定访问入口            |
| Docker Volume                | **PersistentVolumeClaim / Volume**      | 持久化存储抽象                                        |
| Docker Compose（多容器编排） | **Deployment + Service + ConfigMap 等** | K8s 需要多个资源组合来描述一个完整应用                |
| Docker Swarm（集群模式）     | **Kubernetes 集群**                     | 容器编排平台层面的对应                                |
