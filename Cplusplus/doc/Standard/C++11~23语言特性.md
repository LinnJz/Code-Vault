# C++20

下面按提案编号顺序，以 **Before C++20** 和 **Since C++20** 对照的形式介绍C++20核心语言的所有新增特性。

---

## 1. 允许 Lambda 捕获 [=, this] (P0409R2)
**Before C++20**：`[=]` 会隐式捕获 `this`，容易导致歧义和意外的引用捕获。
```cpp
struct S {
    int val = 10;
    auto getLambda() {
        return [=] { return val; };  // 隐式捕获 this，行为等同 [&]
    }
};
```
**Since C++20**：隐式捕获 `this` 被废弃，必须显式使用 `[=, this]` 或 `[=, *this]`。
```cpp
struct S {
    int val = 10;
    auto getLambda() {
        return [=, this] { return val; };   // 显式捕获 this（指针）
        // 或 [=, *this] ⇒ 捕获当前对象的副本
    }
};
```

## 2. `__VA_OPT__` (P0306R4)
**Before C++20**：变参宏中处理多余逗号极其困难，需借助编译器扩展或繁琐技巧。
```cpp
#define LOG(format, ...) printf(format, ##__VA_ARGS__) // GCC 扩展
```
**Since C++20**：`__VA_OPT__` 可根据参数是否为空有条件地插入内容。
```cpp
#define LOG(format, ...) printf(format __VA_OPT__(,) __VA_ARGS__)
```

## 3. 指定初始化器 (P0329R4)
**Before C++20**：只能按顺序初始化聚合体，容易因参数顺序错误引入 bug。
```cpp
struct Point { int x; int y; };
Point p{10, 20};               // 必须记住哪个是 x，哪个是 y
```
**Since C++20**：可以显式指定初始化哪个成员。
```cpp
Point p{.x = 10, .y = 20};   // 明确指定，顺序不可颠倒
```

## 4. 泛型 lambda 的模板参数列表 (P0428R2)
**Before C++20**：泛型 lambda 使用 `auto`，无法直接访问参数类型。
```cpp
auto f = [](auto x) {
    using T = decltype(x);
    // ...
};
```
**Since C++20**：可以直接使用模板语法。
```cpp
auto f = []<typename T>(T x) {
    using Type = T;
    // ...
};
```

## 5. 位域的默认成员初始化器 (P0683R1)
**Before C++20**：位域不能有默认初始值。
```cpp
struct S {
    int flag : 1;           // 无默认值
    S() : flag(1) {}        // 必须在构造函数中初始化
};
```
**Since C++20**：可以直接为位域指定默认值。
```cpp
struct S {
    int flag : 1 = 1;       // 默认初始值为 1
};
```

## 6. 类模板参数推导中的初始化列表构造函数 (P0702R1)
**Before C++20**：使用初始化列表推导类模板参数时可能产生错误结果（如 `std::vector v{1, 2, 3}` 推导为 `std::vector<int>` 但可能意外调用 initializer_list 构造函数）。
```cpp
std::vector v{1, 2, 3};    // C++17: 推导为 std::vector<int>？实际行为可能不确定
```
**Since C++20**：调整了推导规则，使初始化列表构造函数优先匹配，行为更可预测。
```cpp
std::vector v{1, 2, 3};    // C++20: 正确推导为 std::vector<int>
```

## 7. const&-限定的成员指针 (P0704R1)
**Before C++20**：const-限定的成员指针不能像普通 const-限定的引用一样工作。
```cpp
struct S { void f() const & {} };
void (S::*pmf)() const & = &S::f;    // C++17 前不允许
```
**Since C++20**：允许 const&-限定的成员指针存在并被调用。
```cpp
struct S { void f() const & {} };
void (S::*pmf)() const & = &S::f;    // C++20: 合法
```

## 8. 概念 (P0734R0)
**Before C++20**：使用 SFINAE、`std::enable_if` 等技巧约束模板，语法复杂。
```cpp
template<typename T, typename = std::enable_if_t<std::is_integral_v<T>>>
T add(T a, T b) { return a + b; }
```
**Since C++20**：通过 `concept` 和 `requires` 提供清晰的类型约束。
```cpp
template<std::integral T>
T add(T a, T b) { return a + b; }
```

## 9. 未求值上下文中的 Lambda (P0315R4)
**Before C++20**：不能在 `decltype`、`sizeof` 等未求值上下文中使用 lambda。
```cpp
// C++17 前非法
// decltype([](int x) { return x + 1; }) f;
```
**Since C++20**：允许在未求值上下文中编写 lambda。
```cpp
auto f = decltype([](int x) { return x + 1; }){};
```

## 10. 三向比较运算符 (P0515R3)
**Before C++20**：需要分别重载 `<`, `==`, `>` 等六个运算符。
```cpp
struct T {
    int v;
    bool operator<(const T& o) const { return v < o.v; }
    bool operator==(const T& o) const { return v == o.v; }
    // ...
};
```
**Since C++20**：使用 `<=>` 可自动生成所有比较运算符。
```cpp
struct T {
    int v;
    auto operator<=>(const T&) const = default;
};
```

## 11. 简化隐式 Lambda 捕获 (P0588R1)
**Before C++20**：`[=]` 或 `[&]` 的隐式捕获规则在某些情况下存在二义性。
```cpp
int x = 10;
[=] { return x; };  // 隐式捕获
```
**Since C++20**：规范更清晰地定义了何时需要捕获，减少隐式行为的混淆。
```cpp
int x = 10;
[x] { return x; };  // 建议显式捕获，使意图更清晰
```

## 12. 基于范围的 for 循环的初始化语句 (P0614R1)
**Before C++20**：`for` 循环中不能同时有初始化器。
```cpp
auto range = getRange();
for (auto& elem : range) { /* ... */ }   // range 生命周期可能过长
```
**Since C++20**：可在 `for` 循环头部包含一个初始化语句。
```cpp
for (auto range = getRange(); auto& elem : range) { /* ... */ }   // 生命周期受限
```

## 13. 默认可构造和可赋值的无状态 Lambda (P0624R2)
**Before C++20**：lambda 的默认构造函数和拷贝赋值运算符被删除。
```cpp
auto f = [](int x) { return x + 1; };
decltype(f) g = f;            // OK
// decltype(f) h;             // 错误：默认构造函数被删除
```
**Since C++20**：捕获列表为空的 lambda 是默认可构造和可赋值的。
```cpp
auto f = [](int x) { return x + 1; };
decltype(f) h;                // OK，默认构造
```

## 14. 默认特殊成员函数的类型不匹配 (P0641R2)
**Before C++20**：显式默认的函数如果签名不匹配，会导致程序非良构。
```cpp
struct S {
    S(int) = default;          // C++17: 错误
};
```
**Since C++20**：签名不匹配的默认函数会被静默删除（`delete`），而非直接报错。
```cpp
struct S {
    S(int) = default;          // C++20: 该构造函数被隐式删除
};
```

## 15. 对特化进行访问检查 (P0692R1)
**Before C++20**：显式特化和显式实例化中的某些访问检查过于严格。
```cpp
template<typename T> struct S {
private:
    int secret;
};
// C++17: 某些上下文中 explicit specialization 的访问检查仍然严格
template<> struct S<int> { int secret; };  // ?
```
**Since C++20**：放宽了显式特化和显式实例化时的访问检查规则。
```cpp
template<> struct S<int> { int secret; };  // 允许访问，即使 member 是 private
```

## 16. ADL 和不可见的函数模板 (P0846R0)
**Before C++20**：通过 ADL 调用函数模板时，若名称不可见，则查找失败。
```cpp
namespace N { template<typename T> void f(T); }
N::f(10);                     // C++17: 必须可见
```
**Since C++20**：即使模板名称通过常规查找不可见，ADL 仍可成功调用。
```cpp
namespace N { template<typename T> void f(T); }
f(10);                        // C++20: ADL 可找到 N::f<int>
```

## 17. 指定何时需要 constexpr 函数定义进行常量求值 (P0859R0)
**Before C++20**：`constexpr` 函数的实例化时机不明确。
```cpp
template<typename T> constexpr T max(T a, T b) { return a > b ? a : b; }
constexpr int x = max(3, 4);   // 函数可能被实例化，也可能不被？
```
**Since C++20**：要求在常量表达式求值上下文中，必须提供 `constexpr` 函数的定义。
```cpp
constexpr int x = max(3, 4);   // C++20: 保证此时函数定义已可用
```

## 18. 属性 [[likely]] 和 [[unlikely]] (P0479R5)
**Before C++20**：分支预测提示依赖编译器扩展（如 `__builtin_expect`）。
```cpp
if (__builtin_expect(x > 0, 1)) { /* ... */ }
```
**Since C++20**：使用标准属性提供分支预测信息。
```cpp
if (x > 0) [[likely]] { /* ... */ } else [[unlikely]] { /* ... */ }
```

## 19. 使 typename 更可选 (P0634R3)
**Before C++20**：许多需要 `typename` 的上下文中，不能省略该关键字。
```cpp
template<typename T> struct S {
    typename T::value_type get();  // 必须写 typename
};
```
**Since C++20**：在明显为类型的上下文中，`typename` 可以省略。
```cpp
template<typename T> struct S {
    T::value_type get();           // 省略 typename，仍合法
};
```

## 20. Lambda 初始化捕获中的包展开 (P0780R2)
**Before C++20**：在 lambda 初始化捕获中无法进行包展开。
```cpp
template<int... Is>
auto f() {
    // C++17: 无法捕获 Is...
    return [...args]{}; // 错误
}
```
**Since C++20**：允许在初始化捕获中使用包展开。
```cpp
template<int... Is>
auto f() {
    return [...args = Is] {};   // 合法，args 捕获了参数包
}
```

## 21. 属性 [[no_unique_address]] (P0840R2)
**Before C++20**：即使空类型成员也可能占用一个字节的空间。
```cpp
struct Empty { };
struct S {
    Empty e;
    int i;     // 至少占用 8 字节（通常）
};
```
**Since C++20**：使用 `[[no_unique_address]]` 允许空成员共享地址，优化布局。
```cpp
struct S {
    [[no_unique_address]] Empty e;
    int i;     // 可能只占用 4 字节
};
```

## 22. 条件平凡的特殊成员函数 (P0848R3)
**Before C++20**：在概念的作用下，更易于定义有条件平凡的特殊成员函数。
```cpp
// SFINAE 技巧复杂
```
**Since C++20**：利用概念，可以更清晰地编写条件平凡性。
```cpp
template<typename T>
struct MyType {
    MyType() requires std::is_trivially_default_constructible_v<T> = default;
};
```

## 23. 放松结构化绑定的自定义点查找规则 (P0961R1)
**Before C++20**：`get()` 自定义点的查找规则较严格，可能导致 SFINAE 失败。
```cpp
// 某些情况下的 get 查找可能失败
```
**Since C++20**：放宽了规则，使更多自定义点有效。
```cpp
struct S { int a; int b; };
// 即使没有宏定义，结构化绑定也可用于 S
auto [x, y] = S{1, 2};   // 合法
```

## 24. 放松范围-for 循环的自定义点查找规则 (P0962R1)
**Before C++20**：若某个成员 `begin()` 存在但不可用，则 ADL 查找失败。
```cpp
struct R {
    int begin();    // 成员，但非 const？
    int end();
};
// C++17: for (auto& x : r) 可能编译失败
```
**Since C++20**：只有当 `begin` 和 `end` 两个成员都可用时，才会使用成员解释，否则回退到 ADL。
```cpp
R r;
for (auto& x : r) { /* ... */ }     // C++20: 可能通过 ADL 工作
```

## 25. 允许结构化绑定到可访问成员 (P0969R0)
**Before C++20**：结构化绑定的成员必须是 public。
```cpp
struct S {
    int a;
private:
    int b;                 // b 无法通过结构化绑定访问
};
// auto [x, y] = S{1, 2}; // C++17: 错误，私有成员
```
**Since C++20**：只要成员在该上下文中可访问即可，不一定要求 public。
```cpp
struct S {
    int a;
private:
    int b;
};
auto [x, y] = S{1, 2};  // C++20: 若在成员函数或友元中，合法
```

## 26. 销毁 operator delete (P0722R3)
**Before C++20**：`operator delete` 不会自动调用析构函数。
```cpp
void* allocate(size_t size);
// 需要在 delete 前手动调用析构函数
```
**Since C++20**：可定义销毁 `delete`，自动调用析构函数。
```cpp
struct Alloc {
    void operator delete(Alloc* ptr, std::destroying_delete_t) {
        ptr->~Alloc();       // C++20: 自动调用析构
        ::operator delete(ptr);
    }
};
```

## 27. 类类型在非类型模板参数中 (P0732R2)
**Before C++20**：非类型模板参数只能是基本类型。
```cpp
template<const char* s>   // C++17: 指针文字不可靠
struct X {};
```
**Since C++20**：允许使用类类型（满足强结构相等性）作为非类型模板参数。
```cpp
struct FixedString {
    char chars[5] = {};
    constexpr FixedString(const char* s) { /* copy chars */ }
};
template<FixedString S>
struct Y {};
Y<FixedString("hello")> y;   // C++20: 合法
```

## 28. 弃用通过 [=] 隐式捕获 this 的一些用法 (P0806R2)
**Before C++20**：`[=]` 会隐式捕获 `this`，可能引起歧义。
```cpp
[=] { return val; };  // 隐式捕获 this
```
**Since C++20**：该用法被弃用，需显式捕获 `this`。
```cpp
[=, this] { return val; };  // 显式捕获
```

## 29. `explicit(bool)` (P0892R2)
**Before C++20**：`explicit` 是固定的，不能根据模板参数等条件启用。
```cpp
template<typename T>
struct S {
    // 很难根据条件决定 explicit
};
```
**Since C++20**：`explicit` 可接收 `bool` 表达式，实现条件显式。
```cpp
template<typename T>
struct S {
    explicit(!std::is_integral_v<T>)
    operator T() const { /* ... */ }
};
```

## 30. 整合特性测试宏 (P0941R2)
**Before C++20**：特性测试宏分散，缺乏统一标准。
```cpp
// 没有统一的方式检测 noexcept 等特性
```
**Since C++20**：所有标准特性测试宏被正式纳入标准，定义更明确。
```cpp
#if __cpp_consteval
// consteval 可用
#endif
```

## 31. 禁止具有用户声明构造函数的聚合 (P1008R1)
**Before C++20**：包含用户声明的构造函数（即使是 `= default`）仍可成为聚合。
```cpp
struct S {
    S() = default;   // C++17: S 仍是聚合
};
```
**Since C++20**：只要存在用户声明的构造函数，该类就不再是聚合。
```cpp
struct S {
    S() = default;   // C++20: S 不是聚合
};
// S s{1, 2};       // 错误
```

## 32. constexpr 虚函数 (P1064R0)
**Before C++20**：虚函数不能用于常量表达式。
```cpp
struct Base {
    virtual int value() const { return 0; }
};
// constexpr 上下文无法调用 value()
```
**Since C++20**：允许在常量表达式中进行虚拟派发。
```cpp
struct Base {
    virtual int value() const { return 0; }
};
struct Der : Base {
    int value() const override { return 42; }
};
constexpr int v = Der{}.value();   // C++20: 合法
```

## 33. 比较一致性改进 (P1120R0)
**Before C++20**：比较运算符的某些行为不一致。
```cpp
enum A { a };
enum B { b };
// a == b; 可能产生警告或无警告，行为模糊
```
**Since C++20**：弃用了不同枚举类型之间的比较，提高了比较的一致性。
```cpp
enum A { a };
enum B { b };
// a == b; C++20: 弃用警告
```

## 34. `char8_t` (P0482R6)
**Before C++20**：`u8` 字面量基于 `char`，与 UTF-8 数据不严格匹配。
```cpp
const char* utf8 = u8"Hello";   // C++17: 类型为 const char*
```
**Since C++20**：`u8` 产生 `char8_t` 类型，与 `char` 区分。
```cpp
const char8_t* utf8 = u8"Hello";  // C++20: 类型为 const char8_t*
```

## 35. `std::is_constant_evaluated()` (P0595R2)
**Before C++20**：无标准方法检测当前是否处于常量求值上下文。
```cpp
constexpr int compile_or_runtime() {
    // 无法区分编译期与运行时
    return 42;
}
```
**Since C++20**：`std::is_constant_evaluated()` 提供该检测能力。
```cpp
#include <type_traits>
constexpr int compile_or_runtime() {
    if (std::is_constant_evaluated()) {
        return 42;       // 编译期路径
    } else {
        return 99;       // 运行时路径
    }
}
```

## 36. constexpr try-catch 块 (P1002R1)
**Before C++20**：`constexpr` 函数不能包含 `try`/`catch`。
```cpp
constexpr int f() {
    // try { ... } catch (...) { }  // C++17: 错误
    return 0;
}
```
**Since C++20**：允许在 `constexpr` 函数中使用 `try-catch`，但不允许在常量求值时抛出。
```cpp
constexpr int f() {
    try { return 0; } catch (...) { return 1; }
}
```

## 37. 即时函数 (`consteval`) (P1073R3)
**Before C++20**：`constexpr` 函数既可在编译期也可在运行时执行。
```cpp
constexpr int square(int n) { return n * n; }
int x = square(2);          // 运行时或编译期？
```
**Since C++20**：`consteval` 强制必须在编译期执行。
```cpp
consteval int square(int n) { return n * n; }
int x = square(2);          // 编译期，若无法常量求值则错误
```

## 38. 嵌套内联命名空间 (P1094R2)
**Before C++20**：不能在嵌套命名空间中直接声明内联。
```cpp
// namespace A::inline B { }  C++17: 语法错误
```
**Since C++20**：允许 `namespace A::inline B { }` 等嵌套内联形式。
```cpp
namespace A::inline B {
    // 内容
}
```

## 39. 另一种处理受限声明的方法 (P1141R2)
**Before C++20**：受限函数模板需要显式使用 `requires` 子句。
```cpp
template<typename T>
requires std::integral<T>
void f(T x);
```
**Since C++20**：支持更简洁的缩写函数模板语法。
```cpp
template<std::integral T>
void f(T x);
```

## 40. 有符号整数是二补码 (P1236R1)
**Before C++20**：有符号整数的表示允许补码、反码等多种方式。
```cpp
// 有符号整数溢出行为可能是实现定义的
```
**Since C++20**：标准强制要求使用二补码，并定义了位操作的行为。
```cpp
int x = -1;
unsigned int y = x;          // 行为确定，为 2^N - 1
```

## 41. `dynamic_cast` 和多态 `typeid` 在常量表达式中 (P1327R1)
**Before C++20**：`dynamic_cast` 不能在编译期使用。
```cpp
struct Base { virtual ~Base() = default; };
struct Der : Base {};
constexpr Der d;
// constexpr const Base* b = dynamic_cast<const Base*>(&d);   // C++17: 错误
```
**Since C++20**：允许在常量表达式中进行安全的虚基类转换。
```cpp
constexpr const Base* b = dynamic_cast<const Base*>(&d);   // C++20: 合法
```

## 42. 在 constexpr 内部更改联合体的活动成员 (P1330R0)
**Before C++20**：常量表达式中不能更换联合体的活动成员。
```cpp
union U { int i; float f; };
constexpr U u = { .i = 0 };
// u.f = 3.14f;         // C++17: 常量表达式错误
```
**Since C++20**：允许在编译期切换联合的活动成员。
```cpp
constexpr U u = [] {
    U u; u.i = 0;
    u.f = 3.14f;        // C++20: 合法
    return u;
}();
```

## 43. 协程 (P0912R5)
**Before C++20**：必须使用第三方库或操作系统的协程支持，无标准语法。
```cpp
// Boost.Coroutine 等
```
**Since C++20**：`co_await`、`co_yield`、`co_return` 成为语言关键字。
```cpp
#include <coroutine>
class task { /* promise 类型等 */ };
task gen() {
    co_yield 1;
    co_return 2;
}
```

## 44. 聚合体的括号初始化 (P0960R3)
**Before C++20**：聚合体只能用花括号列表初始化。
```cpp
struct S { int x, y; };
S s{1, 2};                 // 只能这样
```
**Since C++20**：可以使用圆括号列表初始化聚合体。
```cpp
S s(1, 2);                 // 圆括号也在某些上下文中可用
```

## 45. 数组大小在新表达式中可推导 (P1009R2)
**Before C++20**：`new[]` 必须显式指定大小。
```cpp
int* arr = new int[3]{1, 2, 3};  // 必须写 3
```
**Since C++20**：如果初始化列表提供足够信息，大小可以省略。
```cpp
int* arr = new int[]{1, 2, 3};   // 编译器推导为 3
```

## 46. 模块 (P1103R3)
**Before C++20**：通过 `#include` 管理依赖。
```cpp
// main.cpp
#include "lib.h"
```
**Since C++20**：使用 `module` 和 `import` 语义管理代码单元。
```cpp
// lib.ixx
export module lib;
export int f() { return 42; }
// main.cpp
import lib;
int x = f();
```

## 47. 更强的 Unicode 要求 (P1041R4, P1139R2)
**Before C++20**：`char16_t` 和 `char32_t` 字面量的实现可能不一致。
```cpp
// 'A' 的编码可能不是 0x41？
```
**Since C++20**：标准明确要求 `char16_t` 使用 UTF-16，`char32_t` 使用 UTF-32。
```cpp
static_assert(u'A' == 0x41);   // 保证成立
```

## 48. `<=>` `!=` `==` (P1185R2)
**Before C++20**：`<=>` 与 `==` 互不干扰。
```cpp
// 需要分别重载
```
**Since C++20**：默认的 `<=>` 会自动生成 `==` 和 `!=`。
```cpp
struct T { int v; auto operator<=>(const T&) const = default; };
bool b = T{1} == T{2};   // C++20: 合法，自动生成
```

## 49. 显式默认函数可带不同异常规范 (P1286R2)
**Before C++20**：显式默认的函数必须拥有与隐式版本兼容的异常规范。
```cpp
struct S {
    S(S&&) noexcept(false) = default;    // C++17: 错误
};
```
**Since C++20**：取消了这一限制，允许异常规范不匹配，此时函数可能被隐式删除。
```cpp
struct S {
    S(S&&) noexcept(false) = default;    // C++20: 允许，但可能被删除
};
```

## 50. lambda 捕获可指定存储类说明符 (P1091R3)
**Before C++20**：lambda 捕获不能使用 `static` 或 `thread_local`。
```cpp
int x = 10;
auto f = [x] { return x; };    // 不能声明为 static
```
**Since C++20**：允许在 lambda 捕获中使用存储类说明符。
```cpp
auto f = [static x = 10] { return x; };
```

## 51. 允许转换为未知大小的数组 (P0388R4)
**Before C++20**：引用或指针无法从已知大小的数组转换为未知大小的数组。
```cpp
int arr[3] = {1, 2, 3};
// int(&)[] ref = arr;        // C++17: 错误
```
**Since C++20**：引入了对未知大小数组的引用/指针的转换。
```cpp
int arr[3] = {1, 2, 3};
int(&)[] ref = arr;           // C++20: 合法
```

## 52. constexpr 容器操作 (P0784R7)
**Before C++20**：`constexpr` 函数中不能使用动态内存分配（`new`/`delete`）。
```cpp
constexpr int f() {
    // int* p = new int;       // C++17: 错误
    return 0;
}
```
**Since C++20**：允许在常量表达式中使用 `new` 和 `delete`（只要分配和释放在同一求值内配对）。
```cpp
constexpr int f() {
    int* p = new int(42);
    int ret = *p;
    delete p;
    return ret;
}
```

## 53. 弃用 volatile 的一些用法 (P1152R4)
**Before C++20**：volatile 左值的简单赋值在标准层面被允许。
```cpp
volatile int v = 10;
v = 20;                  // C++17: 可能产生警告，但合法
```
**Since C++20**：这种赋值被弃用。
```cpp
volatile int v = 10;
v = 20;                  // C++20: 弃用警告
```

## 54. `constinit` (P1143R2)
**Before C++20**：无法强制要求静态存储期变量在编译期初始化。
```cpp
int x = static_init_runtime();  // 可能运行时初始化
```
**Since C++20**：`constinit` 确保变量是静态/编译期初始化的。
```cpp
constinit int x = 42;           // 编译期初始化，不可运行时初始化
```

## 55. 弃用下标中的逗号运算符 (P1161R3)
**Before C++20**：`a[b,c]` 是合法的（逗号运算符）。
```cpp
int arr[2];
arr[0, 1] = 5;              // C++17: 按下标 1 处理，令人困惑
```
**Since C++20**：该用法被弃用。
```cpp
arr[0, 1] = 5;              // C++20: 弃用警告，建议使用 arr[0][1] 等
```

## 56. 带有消息的 `[[nodiscard]]` (P1301R4)
**Before C++20**：`[[nodiscard]]` 只能不附带任何消息。
```cpp
struct [[nodiscard("理由")]] S;   // C++17: 错误
```
**Since C++20**：可以添加解释字符串。
```cpp
[[nodiscard("Handle the returned value")]] int important();
```

## 57. constexpr 函数中的平凡默认初始化 (P1331R2)
**Before C++20**：`constexpr` 构造函数必须初始化每个成员。
```cpp
struct S { int x; };
constexpr S s;              // C++17: 错误，x 未初始化
```
**Since C++20**：允许在常量上下文中进行平凡默认初始化（存在未初始化成员）。
```cpp
struct S { int x; };
constexpr S s;              // C++20: 合法，x 未初始化（值不确定）
```

## 58. constexpr 函数中未求值的 asm 声明 (P1668R1)
**Before C++20**：`constexpr` 函数中不能包含 `asm` 声明。
```cpp
constexpr int f() {
    // asm("nop");          // C++17: 错误
    return 42;
}
```
**Since C++20**：允许存在 `asm` 声明，只要该部分在常量求值中未被实际执行。
```cpp
constexpr int f() {
    if (!std::is_constant_evaluated())
        asm("nop");        // C++20: 合法
    return 42;
}
```

## 59. `using enum` (P1099R5)
**Before C++20**：必须使用 `using` 单独引入枚举值或始终使用限定名。
```cpp
enum Color { Red, Green };
// 需要逐个引入或 Color::Red
```
**Since C++20**：`using enum` 可一次性引入所有枚举值。
```cpp
using enum Color;
auto x = Red;  // OK
```

## 60. 为指定比较类别合成三路比较 (P1186R3)
**Before C++20**：合成三路比较的行为在某些情况下不完整。
```cpp
// 某些比较操作需要手动重载
```
**Since C++20**：当指定比较类别（`std::strong_ordering` 等）时，编译器可自动合成缺失的比较运算符。
```cpp
struct T {
    int v;
    std::strong_ordering operator<=>(const T&) const = default;
};
// 所有比较运算符自动可用
```

## 61. 构造函数的 `[[nodiscard]]` (P1771R1) (defect report)
**Before C++20**：`[[nodiscard]]` 不能应用于构造函数。
```cpp
struct S { [[nodiscard]] S(int) {} };  // C++17: 无效
```
**Since C++20**：构造函数可标记为 `[[nodiscard]]`，若构造后丢弃对象则发出警告。
```cpp
struct S { [[nodiscard]] S(int) {} };
S{42};               // C++20: 警告，可能意外
```

## 62. 别名模板的类模板参数推导 (P1814R0)
**Before C++20**：别名模板不能从初始化器推导参数。
```cpp
template<typename T> using Vec = std::vector<T>;
// Vec v{1, 2, 3};        // C++17: 无法推导
```
**Since C++20**：支持别名模板的类模板参数推导。
```cpp
Vec v{1, 2, 3};           // C++20: 推导为 std::vector<int>
```

## 63. 聚合体的类模板参数推导 (P1816R0, P2082R1)
**Before C++20**：聚合体（如 `std::array`）需要显式指定集合大小。
```cpp
std::array arr{1, 2, 3};   // C++17: 需要推导指南
```
**Since C++20**：允许聚合体模板参数推导。
```cpp
std::array arr{1, 2, 3};   // C++20: 推导为 std::array<int, 3>
```

## 64. 更多隐式移动 (P1825R0)
**Before C++20**：`return` 语句中某些左值不会自动转为右值/移动。
```cpp
std::string f(std::string s) { return s; } // 可能不移动
```
**Since C++20**：更多场景下，`return` 中的局部变量会自动被视为右值（移动）。
```cpp
std::string f(std::string s) { return s; } // C++20: 保证移动
```

## 65. 允许按值默认比较 (P1946R0)
**Before C++20**：默认比较函数必须按引用接受参数。
```cpp
struct T {
    // bool operator==(T) = default;  // C++17: 错误
    bool operator==(const T&) = default; // 只能按引用
};
```
**Since C++20**：允许默认比较运算符按值接受参数。
```cpp
struct T {
    bool operator==(T) = default;       // C++20: 合法
};
```

## 66. 移除 `std::weak_equality` 和 `std::strong_equality` (P1959R0)
**Before C++20**：标准库中定义了 `weak_equality` 和 `strong_equality`（从三向比较的初期阶段遗留）。
```cpp
// C++17::weak_equality, strong_equality 存在
```
**Since C++20**：这些类别被移除，统一使用 `std::weak_ordering`、`std::strong_ordering` 等。
```cpp
// 只使用 std::weak_ordering, std::strong_ordering, std::partial_ordering
```

## 67. 非类型模板参数的不一致性 (P1907R1)
**Before C++20**：某些类型在作为非类型模板参数时出现不一致，例如 `float` 和类类型。
```cpp
// template<float f>  // 可能部分支持，行为不统一
```
**Since C++20**：允许更多的标量类型和类类型（包括浮点）作为非类型模板参数。
```cpp
template<float f>
struct F {};
F<3.14f> f;   // C++20: 合法
```

## 68. 伪析构函数结束对象生命周期 (P0593R6)
**Before C++20**：伪析构函数调用（如 `x.~int()`）不结束对象的生命周期。
```cpp
int x = 42;
x.~int();             // C++17: 不影响生命周期
```
**Since C++20**：伪析构函数调用会结束对象的生命周期。
```cpp
int x = 42;
x.~int();             // C++20: 生命周期结束
```

## 69. 从 T* 转换为 bool 应视为收缩转换 (P1957R2)
**Before C++20**：指针到 `bool` 的转换不被视为收缩转换。
```cpp
struct S { bool b; };
S s{nullptr};          // C++17: 可能不被检测
```
**Since C++20**：`T*` 到 `bool` 的转换被视为收缩转换，会触发诊断。
```cpp
// S s{nullptr};       // C++20: 收缩转换警告
```

---

这些就是 C++20 核心语言的全部新增特性。每个特性都旨在简化代码、增强表达能力或修复旧标准中的不一致问题，配合示例可以清楚地看到它们在日常编程中的差异。

# C++23

## 1. `z` / `Z` 后缀用于有符号 `size_t`（`ssize_t`）(P0330R8)
**Before C++23**：需要手动转换或使用 `static_cast` 得到有符号大小类型。
```cpp
#include <cstddef>
auto n = static_cast<std::ptrdiff_t>(42);
auto m = static_cast<std::size_t>(42);
```

**Since C++23**：直接使用 `z`/`Z` 后缀（有符号），`uz`/`UZ` 用于无符号。
```cpp
#include <cstddef>
auto n = 42z;    // std::ptrdiff_t
auto m = 42uz;   // std::size_t
```

## 2. Lambda 的 `()` 更可选 (P1102R2)
**Before C++23**：无捕获、无说明符且参数为空时仍需写 `()`。
```cpp
auto f = []() { return 42; };
```
**Since C++23**：可以省略空的参数列表。
```cpp
auto f = [] { return 42; };
```

## 3. `if consteval` (P1938R3)
**Before C++23**：需要用 `std::is_constant_evaluated()` 模拟编译期分支。
```cpp
constexpr int compute() {
    if (std::is_constant_evaluated())
        return compile_time_version();
    else
        return runtime_version();
}
```
**Since C++23**：专用语法 `if consteval` 更清晰。
```cpp
constexpr int compute() {
    if consteval {
        return compile_time_version();
    } else {
        return runtime_version();
    }
}
```

## 4. 移除垃圾回收支持 (P2186R2)
**Before C++23**：标准库中保留 `std::declare_reachable` 等无实际实现的 API。
```cpp
#include <memory>
std::declare_reachable(nullptr); // 可编译但无用
```
**Since C++23**：这些名称被正式移除，使用即编译错误。
```cpp
// std::declare_reachable 不再存在
```

## 5. `static_assert` 和 `constexpr if` 中的收窄上下文转换 (P1401R5)
**Before C++23**：`static_assert` 和 `constexpr if` 的条件初始化中禁止缩窄转换。
```cpp
static_assert(unsigned(-1));            // 错误：缩窄转换
if constexpr (unsigned char c = 300; c) { } // 错误
```
**Since C++23**：允许缩窄转换（与普通初始化行为一致，不会导致程序非良构）。
```cpp
if constexpr (unsigned char c = 300; c) { } // 允许，c 被缩窄为 44
```

## 6. 行拼接前去除空白字符 (P2223R2)
**Before C++23**：反斜杠前的空白字符可能影响拼接行为，实现不统一。
```cpp
#define M\
    aaa   // 反斜杠前的空格是否保留？
```
**Since C++23**：标准强制规定在物理行拼接前先去除反斜杠前的空白字符，行为统一。

## 7. 强制规定声明顺序布局 (P1847R4)
**Before C++23**：同一访问段内的非静态数据成员可能被编译器重排。
```cpp
struct S { char a; int b; char c; };
// 地址顺序不保证为 a < b < c
```
**Since C++23**：必须按声明顺序分配地址（填充仍允许，但相对顺序固定）。
```cpp
struct S { char a; int b; char c; };
// 保证 &a < &b < &c
```

## 8. 移除混合宽字符串字面量连接 (P2201R1)
**Before C++23**：允许拼接窄字符串和宽字符串，行为实现定义。
```cpp
auto s = L"hello" " world";   // 可能允许，但有争议
```
**Since C++23**：禁止混合编码的字面量连接，必须类型一致。

```cpp
auto s = L"hello" L" world";  // 正确
// auto t = L"hello" " world"; // 非良构，必须同宽窄
```

## 9. 显式对象成员函数（推导 `this`）(P0847R7)
**Before C++23**：需要为 const/非 const 左值/右值重载多个版本。
```cpp
struct S {
    int value;
    int& get() & { return value; }
    const int& get() const& { return value; }
};
```
**Since C++23**：使用 `this Self&&` 参数一次定义所有情况。
```cpp
struct S {
    int value;
    template<typename Self>
    auto&& get(this Self&& self) {
        return self.value;
    }
};
```

## 10. `auto(x)` 和 `auto{x}` 表达式 (P0849R8)
**Before C++23**：需要显式写出 `std::decay_t` 或临时拷贝。
```cpp
auto tmp = x; // 拷贝一份
use(std::move(tmp));// 或者模板转发
```
**Since C++23**：直接创建纯右值副本，等价于 `std::remove_cvref_t<decltype(x)>(x)`。
```cpp
use(auto(x));   // 创建 x 的 prvalue 副本，丢弃引用和 cv
use(auto{x});   // 同上，列表初始化形式
```

## 11. `#elifdef` 和 `#elifndef` (P2334R1)
**Before C++23**：只能用 `#elif defined(...)` 实现。
```cpp
#ifdef A
    // ...
#elif defined(B)
    // ...
#endif
```
**Since C++23**：新增更直观的指令。
```cpp
#ifdef A
    // ...
#elifdef B
    // ...
#endif
```

## 12. `constexpr` 函数中允许非字面量变量、`goto` 和标签 (P2242R3)
**Before C++23**：`constexpr` 函数内不能定义非字面量类型变量，不能使用 `goto`。
```cpp
constexpr int foo() {
    std::string s = "hello"; // 错误：非平凡析构
    return 42;
}
```
**Since C++23**：允许定义，只要常量求值路径不执行到依赖它们的代码。
```cpp
constexpr int foo() {
    std::string s = "hello"; // 合法，但常量求值时若使用 s 则出错
    if (std::is_constant_evaluated()) // 等价于 if consteval
        return 42;
    else
        return s.size();
}
```

## 13. 一致的字符字面量编码 (P2316R2)
**Before C++23**：字符字面量编码可能依赖实现和源文件编码。
```cpp
char c = 'é';   // 值不确定
```
**Since C++23**：强制要求字符字面量编码与执行字符集一致，消除歧义。
```cpp
char c = 'é';   // 若执行字符集为 UTF-8，则值为 0xC3 0xA9 的截断（取决于 char 有符号性）
```

## 14. 字符集和编码规范化 (P2314R4)
**Before C++23**：源字符集、执行字符集、通用字符名的映射关系松散。
**Since C++23**：明确定义各阶段的编码模型和 Unicode 行为，提高跨平台可移植性。

## 15. 扩展 `for` 循环初始化语句，允许别名声明 (P2360R0)
**Before C++23**：初始化语句只能是声明或表达式，不能是 `using`。
```cpp
for (using T = int; auto x : {1,2,3}) { } // 错误
```
**Since C++23**：允许在初始化语句中使用别名声明。
```cpp
for (using T = int; T x : {1,2,3}) { /* x 为 int */ }
```

## 16. 多维下标运算符 (P2128R6)
**Before C++23**：`operator[]` 只能接受一个参数，多维访问需用 `operator()`。
```cpp
struct Matrix {
    int& operator()(int r, int c);
};
```
**Since C++23**：`operator[]` 可以接受多个参数。
```cpp
struct Matrix {
    int& operator[](int r, int c);
};
Matrix m;
m[1,2] = 3; // 调用 operator[](1,2)
```

## 17. Lambda 上的属性 (P2173R1)
**Before C++23**：Lambda 表达式的属性放置位置受限且支持不完整。
```cpp
auto f = [](int x) [[nodiscard]] { return x; }; // 某些编译器不支持
```
**Since C++23**：明确支持在 lambda 引入符、参数列表、返回类型等多处放置属性。
```cpp
auto f = [] [[nodiscard]] (int x) -> int { return x; };
auto g = [] <typename T> [[deprecated]] (T x) { return x; };
```

## 18. `#warning` (P2437R1)
**Before C++23**：没有标准的方式产生预处理警告。
```cpp
// 依赖编译器扩展
#pragma message("warning: ...")
```
**Since C++23**：标准指令 `#warning`。
```cpp
#warning "This is a warning message"
```

## 19. 移除不可编码的宽字符字面量和多字符宽字符字面量 (P2362R3)
**Before C++23**：允许 `L'ab'` 等多字符宽字面量，行为实现定义。
```cpp
wchar_t a = L'ab';   // 可能允许
```
**Since C++23**：非良构，宽字符字面量必须对应单个可编码的宽字符。
```cpp
wchar_t b = L'Ω';    // 若 Ω 可编码为单个 wchar_t 则 OK
// wchar_t a = L'ab'; // 错误
```

## 20. 复合语句末尾的标签 (P2324R2)
**Before C++23**：标签后必须有语句，即使只是空语句 `;`。
```cpp
void f() {
    goto end;
end: ;   // 需要空语句
}
```
**Since C++23**：允许标签直接放在 `}` 之前，无需后续语句。
```cpp
void f() {
    goto end;
end:      // 合法
}
```

## 21. 带分隔符的转义序列 `\x{...}`、`\u{...}` (P2290R3)
**Before C++23**：十六进制转义 `\x` 没有长度限制，容易意外吸收后续字符；`\u` 必须跟 4 位十六进制。
```cpp
char a = '\x61';          // 小心 'x61' 后紧跟 'b' 会变成 \x61b
char32_t b = U'\U0001F600';
```
**Since C++23**：使用花括号明确边界，且 `\u{}` 可表示任意码点。
```cpp
char a = '\x{61}';
char32_t b = '\u{1F600}'; // 不需要 \U 且长度自由
char32_t c = '\u{61}';
```

## 22. 命名通用字符转义 `\N{name}` (P2071R2)
**Before C++23**：只能用码点表示 Unicode 字符。
```cpp
char32_t smile = U'\U0001F600';
```
**Since C++23**：支持按 Unicode 标准名称转义。
```cpp
char32_t smile = U'\N{GRINNING FACE}';
char a = '\N{LATIN SMALL LETTER A}'; // 'a'
```

## 23. 放宽一些 `constexpr` 限制 (P2448R2)
**Before C++23**：`constexpr` 函数中调用的所有函数都必须是 `constexpr`。
```cpp
constexpr int f(int x) {
    return runtime_only(x); // 错误，runtime_only 非 constexpr
}
```
**Since C++23**：允许调用非 `constexpr` 函数，只要常量求值实际不执行到该调用。
```cpp
constexpr int f(int x) {
    if (std::is_constant_evaluated())
        return 42;
    else
        return runtime_only(x); // 合法，常量求值走另一分支
}
```

## 24. 更简单的隐式移动 (P2266R3)
**Before C++23**：`return` 局部变量时自动移动的条件较严格（例如形参不被视为移动候选）。
```cpp
std::string f(std::string&& s) {
    return s;   // 可能复制而非移动
}
```
**Since C++23**：任何返回局部变量或形参的 id-expression 都自动视为右值（xvalue），优先移动。
```cpp
std::string f(std::string&& s) {
    return s;   // 现在隐式移动
}
```

## 25. `static operator()` (P1169R4)
**Before C++23**：函数调用运算符必须是非静态成员。
```cpp
struct S {
    int operator()(int x) const { return x; }
};
S{}(5); // 需要对象
```
**Since C++23**：`operator()` 可为静态，无需对象调用。
```cpp
struct S {
    static int operator()(int x) { return x; }
};
S::operator()(5);   // 直接通过类型调用
```

## 26. 可选扩展浮点类型的要求 (P1467R9)
**Before C++23**：无标准化扩展浮点类型（如 `float16_t`）。
**Since C++23**：标准定义了 `std::float16_t`、`std::bfloat16_t` 等为可选类型，实现可提供，并提供特征宏。
```cpp
#ifdef __STDCPP_FLOAT16_T__
#include <stdfloat>
std::float16_t x = 1.0f16;
#endif
```

## 27. 从继承的构造函数中推导类模板参数 (P2582R1)
**Before C++23**：CTAD 不能从继承的构造函数推导模板参数。
```cpp
template<typename T> struct Base { Base(T); };
template<typename T> struct Derived : Base<T> {
    using Base<T>::Base;
};
Derived d(42); // C++20 错误，无法推导 T
```
**Since C++23**：支持从继承构造函数推导。
```cpp
Derived d(42); // 推导 T = int
```

## 28. 属性 `[[assume]]` (P1774R8)
**Before C++23**：依赖非标准 `__assume` 或 `__builtin_expect`。
```cpp
__assume(x > 0);
```
**Since C++23**：标准属性提供优化假设，若条件为假则行为未定义。
```cpp
[[assume(x > 0)]];
```

## 29. 支持 UTF-8 作为可移植源文件编码 (P2295R6)
**Before C++23**：源文件编码实现定义，常需 `BOM` 或编译选项。
**Since C++23**：标准明确要求编译器接受 UTF-8 编码的源文件（无 BOM 也可），跨平台行为一致。
```cpp
// 源文件保存为 UTF-8 without BOM
auto s = u8"你好"; // 行为明确
```

## 30. `static operator[]` (P2589R1)
**Before C++23**：下标运算符只能是成员非静态函数。
**Since C++23**：允许声明为静态，直接通过类名调用。
```cpp
struct S {
    static int operator[](int idx) { return idx * 10; }
};
int x = S[3]; // 30
```

## 31. `constexpr` 函数中允许 `static constexpr` 变量 (P2647R1)
**Before C++23**：`constexpr` 函数内不能定义任何静态变量。

```cpp
constexpr int f() {
    static int x = 0; // 错误：静态存储期
    return x;
}
```
**Since C++23**：允许定义 `static constexpr` 局部变量。
```cpp
constexpr int f() {
    static constexpr int value = 42;
    return value;
}
```

## 32. 基于范围的 `for` 循环初始化器中延长临时对象生命周期 (P2644R1, P2718R0, CWG2659)
**Before C++23**：范围 `for` 的初始化语句中创建的临时对象可能提前析构。
```cpp
for (auto& x : std::vector{1,2,3}) { } // 危险，临时 vector 在循环前销毁
```
**Since C++23**：初始化语句中创建的临时对象的生命周期延长至整个循环。
```cpp
for (auto vec = std::vector{1,2,3}; auto& x : vec) {
    // vec 存活直到循环结束，安全
}
```

## 缺陷报告 (DR) 修复

以下特性为 C++23 对 C++20 及之前标准的修正。

## 33. DR11：更改 lambda 尾部返回类型的范围 (P2036R3, P2579R0)
**Before C++23**：lambda 尾部返回类型不能引用参数或捕获的变量。
```cpp
auto add = [](auto a, decltype(a) b) -> decltype(a + b) { return a + b; }; // 错误
```
**Since C++23**：允许尾部返回类型使用参数和捕获。
```cpp
auto add = [](auto a, decltype(a) b) -> decltype(a + b) { return a + b; }; // OK
```

## 34. DR20：有意义的导出 (P2615R1)
**Before C++23**：模块中 `export { }` 空导出块的行为模糊。
**Since C++23**：空导出块不产生效果，且所有 `export` 必须附着到实体上，消除歧义。

```C++
// 修复了 export 的无效使用
export module M;
export { }  // 空导出块不再被视为错误但无效果，行为更一致
```

## 35. DR20：`consteval` 向上传播 (P2564R3)
**Before C++23**：立即函数（consteval）的常量求值上下文可能被意外逃逸。
**Since C++23**：强制立即函数的常量求值上下文向上传播，防止降级为非 consteval。

```C++
consteval int inner() { return 42; }
consteval int outer() {
    // 在一些转型或 lambda 中若不传播，可能导致非 consteval 路径
    return inner();
}
// C++23 保证 immediate 传播，防止隐式降级
```

## 36. DR98：使用 Unicode 标准附件 31 的 C++ 标识符语法 (P1949R7)
**Before C++23**：标识符合法字符集基于旧标准，不支持许多现代 Unicode 字符。
**Since C++23**：采纳 Unicode UAX #31，允许更多字符作为标识符。

```cpp
int 变量 = 3;   // 合法且跨平台一致
```

## 37. DR11：允许重复的属性 (P2156R1)
**Before C++23**：重复出现同一属性可能导致编译错误。
```cpp
[[maybe_unused, maybe_unused]] int x; // 错误
```
**Since C++23**：允许重复，多余实例被忽略。
```cpp
[[maybe_unused, maybe_unused]] int x; // 合法
```

## 38. DR20：调整特性测试宏 `__cpp_concepts` 的值 (P2493R0)
**Before C++23**：`__cpp_concepts` 的值可能与 C++20 最终标准不一致。
**Since C++23**：调整至 `202002L`，与 C++20 最终值对齐。

```C++
// 宏值变化，用于检测标准版本
#if __cpp_concepts >= 202002L
// ...
#endif
```

## 39. DR98：放宽 `wchar_t` 的要求以符合现有实践 (P2460R2)
**Before C++23**：标准对 `wchar_t` 的编码和大小要求过严，与一些实现冲突。
**Since C++23**：放宽要求，允许 `wchar_t` 为 `char16_t` 或 `char32_t` 的别名，提高可移植性。

```C++
// 不改变日常代码，但提高了可移植性（尤其在 Windows/Unix 之间）
static_assert(sizeof(wchar_t) == 2 or sizeof(wchar_t) == 4); // 现在都能满足要求
```

## 40. DR11：常量表达式中使用未知指针和引用 (P2280R4)
**Before C++23**：常量表达式中对指向未知对象的指针进行某些操作（如比较）可能非法。
**Since C++23**：允许更多操作（如 `<`、`>`），只要不实际访问指向的值。

```C++
// C++23 前（某些操作禁止）
constexpr const int* p = nullptr;
constexpr bool b = p == nullptr; // OK
constexpr bool b2 = p < nullptr; // 可能失败

// C++23 起更多操作被允许，只要不进行值访问
```

## 41. DR20：相等的运算符反转查找 (P2468R2)
**Before C++23**：当同时存在成员 `!=` 和自由 `==` 时可能产生二义性，且 `a != b` 不自动重写为 `!(a == b)`。
**Since C++23**：`!=` 优先重写为 `!(a == b)`，并禁止导致二义性的重载组合。

```C++
struct X {
    bool operator==(const X&) const;
};
// 现在 X{} != X{} 可自动重写为 !(X{} == X{})，不需要显式定义 !=
```

## 42. DR20：`char8_t` 兼容性和可移植性修复 (P2513R4)
**Before C++23**：`char8_t` 与 `char`/`unsigned char` 之间的隐式转换规则不一致，标准库支持不完整。
**Since C++23**：修复转换规则，完善标准库对 `char8_t` 的支持（如 I/O、格式化）。

```C++
// 修复后，某些标准库函数的 char8_t 重载更合理
std::u8string s = u8"hello";
// 涉及 I/O 和格式化的接口更加一致
```

## 43. DR98/11：澄清诊断指令的报告，并允许在模板上下文中对非值依赖表达式进行 `static_assert` (CWG2518)
**Before C++23**：模板定义中对非依赖表达式使用 `static_assert` 可能被延迟到实例化，或某些实现拒绝。
**Since C++23**：明确允许，只要表达式在模板定义时即可求值（不依赖模板参数），诊断在模板定义时发出。
```cpp
template<typename T>
void f() {
    static_assert(sizeof(int) == 4, "int not 4 bytes"); // C++23 起正式允许
    // 之前一些实现可能已经支持，现标准化
}
```
