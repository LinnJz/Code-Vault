# C++20 协程 (Coroutines) 

## 概述 

C++20 引入语言级别无栈协程（stackless coroutine），通过 `co_await`、`co_yield`、`co_return` 三个关键字控制协程的**挂起**与**恢复**。编译器将协程执行状态保存到堆上的协程帧（coroutine frame）中，挂起后可随时恢复继续执行。标准库直到 C++23 才提供 `std::generator`；C++20 的协程框架是可定制的底层原语——生产中需自定义返回类型或借助第三方库（如 `cppcoro`、Boost.Asio）。核心价值：以同步风格写异步逻辑、惰性生成器（按需计算、O(1) 内存）、高并发任务调度（无线程切换开销）。

## 协程关键字与挂起点 

三个关键字定义协程行为：

* `co_await expr` 挂起等待 Awaiter 就绪；

* `co_yield expr` 等价于 `co_await promise.yield_value(expr)` 产出值并挂起；

  **表达式求值**：`co_yield e` 会先求值表达式 `e`，然后将结果传递给 `p.yield_value(e)`。

  **`yield_value` 的职责**：`promise` 类型的 `yield_value` 方法负责处理这个值，通常会将值存储起来，并返回一个 `awaitable` 对象。

  **后续的 `co_await`**：接着，`co_await` 操作符会作用于这个 `awaitable` 对象，这会决定协程是否以及如何挂起。

  **挂起后可以恢复**：`co_await p.yield_value(e)` 返回的 `awaitable`（通常是 `suspend_always`）让协程挂起，但**调用者可以再次 `resume()`** 它，循环取下一个值。

  **注意**：`co_yield` 还有另一种形式：`co_yield ranges::elements_of(rng)`，它用于逐个产生一个范围（range）中的所有元素。这种形式与 `co_await p.yield_value(e)` 的等价关系不再成立，不能混为一谈。

* `co_return expr` 调用 `return_value(expr)`（无参时调用 `return_void()`）然后调用`co_await promise.final_suspend()`并结束协程体。

  `return_value` 负责把最终结果传给调用者（比如存入 `promise` 的成员变量）。

  `final_suspend` 负责决定是在销毁前挂起（让调用者最后读一下结果），还是立即销毁。

  **最终挂起不可恢复**：虽然 `p.final_suspend()` 可以返回 `suspend_always` 或 `suspend_never`（都是`awaiter`），但**C++ 标准明确规定**：在最终挂起点（final suspend point）恢复协程的行为是**未定义行为（UB）**。这意味着 `co_return` 标志着协程生命周期的**终结**，它的句柄（handle）随后会被销毁或已经 `done()`。

  **注意**：协程体末尾的 `}` 会隐式地等效于 `co_return;`，但前提是 `p.return_void()` 必须存在，否则编译报错。

`co_await expr` 的求值构成一个**挂起点**（suspension point）。编译器按 Awaiter 协议调用三个方法：

```c++
struct Awaiter {
    bool await_ready() const noexcept;
    auto await_suspend(std::coroutine_handle<>) const noexcept;
    auto await_resume() const noexcept;
};
```

* `bool await_ready() const noexcept;`
  * `await_ready` 为 true → **跳过挂起，直接调 `await_resume`**；
  * `await_ready` 为 false → 调 `await_suspend`，根据返回值（void挂起 / bool条件挂起 / handle对称转移）决定是否挂起，若**不挂起**（或抛出异常）则继续调 `await_resume`。

* `auto await_suspend(std::coroutine_handle<>) const noexcept;`

  * | 返回值类型               | 逻辑                                                         | 注意点                                                       |
    | ------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
    | **`void`**               | **无条件挂起**。协程立刻暂停，控制权返回给调用者。           | 最常见，用于标准的异步 IO 或生成器。                         |
    | **`bool`**               | **条件挂起**。  - 返回 `true`：挂起（同 void）。 - 返回 `false`：**取消挂起**，协程继续向下执行，接着调用 `await_resume()`。 | 这个特性非常有用，比如实现“自旋锁”或“立即返回”的优化，避免不必要的上下文切换。 |
    | **`coroutine_handle<>`** | **对称转移（Symmetric Transfer）**。  - 当前协程挂起。 - 立即**恢复（resume）**返回的那个句柄。 | 这是实现**无栈协程高效调度**的核心。它避免了递归恢复导致的栈溢出，允许协程 A 挂起后直接切换到协程 B。 |

  * 当 `await_suspend` 返回 `coroutine_handle` 时，如果它返回的是**当前协程自身的句柄（`this`）**，标准规定这会被视为**未挂起**（相当于 `bool false`），协程会继续执行并调用 `await_resume`，而不是把自己挂起再立即恢复。

  * 如果 `await_suspend(...)` 内部**抛出异常**：

    - 协程**不会挂起**。
    - 异常会向外传播给 `co_await` 的调用者。
    - 此时 **`await_resume()` 不会被调用**（因为 `await_suspend` 失败了，后续语句不执行）。

* `auto await_resume() const noexcept;`

  * 恢复协程返回类型由用户自己定

## co_await 标准执行流程（核心伪代码）

对于表达式 `co_await e`，编译器生成的逻辑大致如下：

```cpp
auto&& awaitable = e;
if (!awaitable.await_ready()) {          // 如果为 true，跳过挂起
    // 尝试挂起当前协程
    if (awaitable.await_suspend(handle) 条件成立) {
        // 协程挂起，控制权返回给调用者（或调用者的恢复者）
        return;
    }
    // 如果条件不成立（未挂起），程序继续向下执行
}
// 协程继续运行（要么 await_ready 为 true，要么 await_suspend 决定不挂起）
auto result = awaitable.await_resume(); 
```

## promise_type 

每个协程返回类型必须内嵌或通过 trait 关联一个 `promise_type`，定义协程完整生命周期协议：

```cpp
struct Task {
    struct promise_type {
        int result{};
        Task get_return_object() {                    // 构造返回对象
            return Task{std::coroutine_handle<promise_type>::from_promise(*this)};
        }
        std::suspend_always initial_suspend() noexcept { return {}; }  // 惰性启动
        std::suspend_always final_suspend() noexcept { return {}; }    // 最终挂起
        void return_value(int v) { result = v; }      // co_return expr
        // void return_void() noexcept {}              // co_return; 或无 co_return 时
        std::suspend_always yield_value(int v) {       // co_yield expr
            result = v; return {};
        }
        void unhandled_exception() { std::terminate(); }
    };
    std::coroutine_handle<promise_type> handle;
};
```

关键约束：`return_value` 与 `return_void` **不能共存**；`co_yield` 存在时隐式允许 `return_void`。`final_suspend()` 返回的 Awaiter 必须可挂起（`await_ready()` 为 `false`），否则协程帧自动销毁后句柄无效（UB）。
